# MVP 与实施计划

状态：规划，以下验收均尚未执行。实现前先完成复用评估和契约冻结。

## 1. 用户闭环

目标：用户用同一角色、两个场景、6–12 个镜头组成一个 30–90 秒小故事。每个镜头通常选用 3–10 秒，必要时使用模型支持的更长片段；整片时长与单次模型生成时长独立。

流程：创建项目 → 导入/编辑剧本 → 审核分镜 → 绑定角色与场景版本 → 上传或生成镜头首帧 → 生成多个候选视频 → 选择 take → 时间线裁切/排序 → 导入声音与字幕 → 导出 MP4 → 保存/恢复项目。

## 2. 工作台草图

```text
┌───────────────── project / save / queue / export ─────────────────┐
│ assets         │ storyboard / takes │ preview                    │
│ characters     │ scenes / shots     │ shot recipe inspector      │
│ locations      │ compare / approve  │ prompts / refs / parameters│
├──────────────────────────────────────────────────────────────────┤
│ timeline: video clips / imported audio / captions                │
└──────────────────────────────────────────────────────────────────┘
```

分镜回答“发生什么、按什么顺序叙述”；时间线回答“用哪个版本、从哪一帧到哪一帧”。二者关联但不能合并成同一个列表。节点画布后续再加，避免第一版要求用户同时理解三种编辑模型。

## 3. 必做与暂缓

必须做：

- 项目、场景、镜头与基本角色/地点资产库。
- 提示词和参考版本快照，手动编辑，LLM 草稿需审核。
- HTTP 视频接口、兼容 LLM 接口与 fake provider。
- take 历史、对比、人工审批、替换。
- 持久队列、共享资源限流、恢复轮询、真实失败提示。
- 基础视频时间线、声音导入、字幕、MP4 导出。
- 项目可携带媒体导出/导入，密钥除外。

暂缓：自动训练 LoRA、3D 场景编辑、无限画布、复杂特效、自动口型、多人实时协同、插件市场、云计费、自动无监督全片生成、移动端、原生桌面打包。保留扩展边界，不先做空壳入口。

## 4. 实施阶段与停止条件

| 阶段 | 交付 | 进入下一阶段的门槛 |
| --- | --- | --- |
| 0：复用验证 | StoryBored 小实验、通用 provider 契约、项目数据样例 | 明确 fork/复用/自建选择；证明外部 HTTP 服务可接入 |
| 1：项目与生成 | 资产、镜头、配方、take、持久任务和手动首帧 | 浏览器关闭/平台重启仍可恢复任务；不存在静默覆盖候选 |
| 2：剪辑与成片 | 轻量时间线、代理、音频、字幕、FFmpeg 导出 | 真实 30–60 秒成片闭环及可重复导出 |
| 3：连续性与扩展 | 状态/依赖检查、图像 provider、第二种视频协议、便携项目 | 不支持能力被明确拒绝；切换 provider 不破坏项目 |
| 4：发布体验 | 安装/启动工具、部署文档、可选桌面包装 | 新机器按照文档完成安装、接入、成片与恢复测试 |

粗略估算：对熟悉前后端和媒体处理的 1–2 名工程师，有限范围可用 MVP 约需 4–8 周；这是规划估计，不是交付承诺。阶段 0 结束后按复用结果和媒体预览难度重新估算。需要真实镜头素材、人工视觉评审和许可检查，不能只靠 UI 截图判定完成。

## 5. 验收清单

1. 一个项目内两次使用同一角色/服装版本，引用正确；不宣称视觉完全一致。
2. 镜头生成 A/B 两个 take，B 不覆盖 A；替换 timeline clip 后保持原定入出点，素材不足时明确提示，不偷偷拉伸。
3. 更改角色参考会标记相关配方过期，但不自动重生成或改变已有时间线。
4. 单一共享视频资源组的 T2V/I2V 不被并发提交；独立服务可单独限流。
5. 模拟网络中断、API/worker 重启、远端重启、下载失败；恢复不盲目重提生成任务。
6. first-frame-only provider 拒绝身份参考/尾帧；未知字段和非法时长被服务端校验。
7. 输出包含实际媒体时长；24 fps 项目导出帧数可核对，音画同步通过人工与程序检查。
8. 项目导出后新数据目录能恢复；无密钥、绝对本机路径或依赖过期 URL。
9. fake provider 测试无外网、无 GPU、无收费；真实调用在独立 opt-in 测试中标识。
10. 30–60 秒样片可以改一个镜头后重导出，其余镜头和声音不被重新生成。

## 6. 首个垂直切片

最先实现的不是全部页面，而是：创建三个镜头 → 每镜头上传首帧 → 用现有 I2V 接口生成 → 选 take → 排序和裁切 → 拼出一个可下载的小故事。与此同时保留版本、任务恢复与项目保存。这个切片能最快检验平台是否真的超出“生成片段工具”。
